Send submissions from any supported form plugin to your HealthCRM as new leads.

== Description ==

Install this plugin, paste your HealthCRM webhook URL once, and every form
submission on your site is captured as a lead — no per-form setup.

Supported form plugins:
* Contact Form 7
* WPForms
* Gravity Forms
* Elementor Pro Forms
* Fluent Forms
* Ninja Forms

Field names like Name, Email, and Phone map automatically; everything else is
stored on the lead too.

== Installation ==

1. In WordPress: Plugins → Add New → Upload Plugin → choose this .zip → Install → Activate.
2. Go to Settings → HealthCRM.
3. Paste the Webhook URL from your CRM (Settings → Configuration → WordPress Forms).
4. (Optional) Paste the Shared Secret if you set one on the integration.
5. Click "Send test lead" to confirm, then submit any form to capture leads.
