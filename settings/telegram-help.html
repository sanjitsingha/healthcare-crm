How to connect the Telegram Bot API

Use the steps below to connect a Telegram bot for reminders, alerts, and CRM updates.

  1. Open Telegram and search for @BotFather.
  2. Start a chat and create a new bot with the command /newbot.
  3. Choose a name and a unique username for your bot, then copy the bot token that BotFather gives you.
  4. Paste the token into your CRM integration settings under Telegram.
  5. Optionally set a webhook or API base URL if your deployment needs direct delivery to your server.
  6. Test the connection by sending a message to the bot from Telegram and confirming it appears in your CRM.

Important: Keep your bot token secret. Do not expose it in client-side code or public repositories.
